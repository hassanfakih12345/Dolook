# مخطط إعادة تصميم واجهات موقع دولوك

## 1. التحليل (الوضع الحالي)

فُحص الموقع على 7 مقاسات: 320، 375، 430 (هواتف) · 768، 1024 (آيباد) · 1280، 1920 (لابتوب وشاشات كبيرة)، على 10 صفحات بالعربي والإنكليزي.

**نقاط القوة (بتضل):** ما في تمرير أفقي بأي مقاس، والألوان والخطوط واضحة، وهوية الأرقام (01، 02…) والزوايا الحادة مميزة.

| المشكلة | الأثر | الدليل |
|---|---|---|
| ترويسات الصفحات الداخلية غير موحّدة (بيضاء عادية مقابل صورة داكنة بصفحات المشاريع) | الموقع بيبيّن كأنه تصميمين | عن الشركة / الأقسام / المشاريع / العملاء / الشهادات / تواصل |
| صور المشاريع منخفضة الدقة ممدودة كخلفية كاملة العرض | صور مغبّشة بأهم مكان | صفحات المشاريع والأقسام |
| 12–26 عنصر قابل للضغط بكل صفحة أقل من 40px | صعوبة الضغط بالموبايل (المعيار ≥ 44px) | الفلاتر 32px، زر اللغة، روابط الفوتر |
| صفحة "عن الشركة" نص متواصل بلا صور أو فواصل بصرية | صعبة القراءة على الهاتف | 375px: صفحة طولها > 3 شاشات نص |
| دعوة "هل لديكم مشروع؟" موجودة بالرئيسية بس | فرص تواصل ضايعة بباقي الصفحات | كل الصفحات الداخلية |
| قائمة الموبايل لائحة روابط بس | ما في اتصال أو واتساب سريع | الهيدر على 375 و768 |
| الهيدر ثابت أبيض فوق صورة الواجهة الرئيسية | بيقطع أول انطباع | الرئيسية |
| الفلاتر بتلتف على 3–4 أسطر بالموبايل | بتاخد نص الشاشة الأولى | /projects على 320–430 |
| صفحة التواصل بلا خريطة أو أيقونات | معلومات التواصل مش سريعة القراءة | /contact |

## 2. الهوية البصرية (ثابتة، ما بتتغيّر)

- **الألوان:** أزرق دولوك `#1b4f9c`، كحلي `#0b1f3a`، أزرق فاتح `#2f6bb8`، رمادي النص `#4a4a4a`، سطح `#f2f4f7`، خطوط `#d8dee8`.
- **الخطوط:** Outfit للإنكليزي، IBM Plex Sans Arabic للعربي.
- **اللوغو** كما هو.
- **العناصر المميزة:** الزوايا الحادة (بدون تدوير للبطاقات)، شارات الأرقام المربعة (01–06)، نقش النقاط (dot-mesh)، التدرّج الكحلي فوق الصور.
- **إضافة منسجمة:** نقش "خطوط المخطط الهندسي" (blueprint grid) خفيف بالكحلي، مستوحى من غلاف البروفايل.

## 3. نظام التصميم (Design System)

**المقاسات (Breakpoints):** 320 → `sm` 640 → `md` 768 (آيباد عمودي) → `lg` 1024 (آيباد أفقي / لابتوب صغير) → `xl` 1280 → `2xl` 1536.

**الطباعة (Typography) متجاوبة بـ `clamp()`:**
| العنصر | موبايل | ديسكتوب |
|---|---|---|
| عنوان الواجهة الرئيسية | 34px | 64px |
| عنوان الصفحة H1 | 30px | 52px |
| عنوان القسم H2 | 26px | 38px |
| نص أساسي | 16px | 17–18px |

**الإيقاع:** مسافة الأقسام 64px موبايل ← 96px ديسكتوب. الحاوية 1280px كحد أقصى مع هوامش 16 / 24 / 32px.

**المكوّنات الأساسية:**
- **زر (Button):** 4 أنواع: أساسي أزرق، ثانوي بإطار، فاتح فوق الصور، نص مع سهم. وارتفاع ≥ 44px دايماً.
- **رأس الصفحة (PageHero):** خلفية كحلية مع نقش النقاط وخطوط المخطط، ومسار التنقل، ورقم القسم، والعنوان، والوصف. وبنسخة "منقسمة" (نص + صورة بإطار) لصفحات المشاريع والأقسام، بحيث تنعرض الصورة بحجمها الطبيعي بلا تمديد.
- **عنوان قسم (SectionHeading):** رقم صغير + عنوان + وصف + رابط جانبي.
- **أيقونات SVG موحّدة:** هاتف، بريد، موقع، واتساب، وثيقة، سهم، صح.
- **حالة التركيز (Focus):** إطار أزرق واضح لكل العناصر لمستخدمي لوحة المفاتيح.

## 4. إعادة تصميم المكوّنات العامة

**الهيدر:**
- شفاف فوق صورة الرئيسية، وبيصير أبيض مع ظل عند التمرير. بباقي الصفحات أبيض دايماً.
- ارتفاعه 72px، وكل الروابط وزر اللغة ≥ 44px، والقائمة الكاملة من مقاس 1024 وأكبر.
- **قائمة الموبايل:** لوحة بكامل الشاشة فيها روابط كبيرة (56px) مع رقم كل قسم، وزر "اطلب عرض سعر"، وأزرار سريعة (اتصال، واتساب، إيميل)، وتبديل اللغة. بتسكّر بـ Esc أو بالنقر على أي رابط، والتمرير خلفها بيوقف.

**الفوتر:**
- شريط دعوة للتواصل بكل الصفحات ("هل لديكم مشروع قادم؟") مع زرّين: عرض سعر، وواتساب.
- 4 أعمدة على الديسكتوب، وعمودين بالموبايل لمجموعات الروابط، مع روابط ≥ 44px على الموبايل.

**زر واتساب العائم:** 48px بالموبايل و56px بالديسكتوب، وبيحترم الحافة السفلية لأجهزة آيفون (safe-area).

## 5. الصفحات

| الصفحة | التصميم الجديد |
|---|---|
| **الرئيسية** | واجهة بعنوان أكبر وهيدر شفاف ← شريط أرقام ← **قسم "عن دولوك"** (نص + كلمة الرئيس التنفيذي + صورتين مشاريع) ← الأقسام الأربعة ← **مشاريع مميزة بتخطيط "بنتو"** (مشروع كبير + 4 صغار) ← القطاعات ← العملاء (لوغوهات رمادية بتتلوّن عند المرور). دعوة التواصل انتقلت للفوتر. |
| **الأقسام** | PageHero ← صفوف متناوبة (صورة / نص) لكل قسم: الرقم، العنوان، الوصف، أول 3 بنود من نطاق العمل، عدد المشاريع، رابط. وبالموبايل بتنعرض فوق بعض. |
| **صفحة قسم** | PageHero منقسم (نص + صورة) ← نطاق العمل بأيقونات ← المشاريع المرتبطة ← دعوة عرض سعر ← أقسام أخرى. |
| **المشاريع** | PageHero ← فلاتر بشريط أفقي قابل للسحب بالموبايل (بدل 4 أسطر) ← شبكة البطاقات. |
| **صفحة مشروع** | PageHero منقسم: الحالة، الاسم، الموقع، نوع العمل، مع الصورة بإطار (بلا تمديد) ← نبذة + بطاقات المعلومات ← معرض الصور ← المخططات وتوزيع المساحات (إن وجدت) ← مشاريع أخرى. |
| **عن الشركة** | PageHero ← المقدمة + 4 أرقام ← كلمة الرئيس التنفيذي ببطاقة كحلية مع علامة اقتباس ← الرؤية والرسالة كبطاقتين ← القيم بشبكة مرقّمة ← القدرات والموارد. |
| **العملاء** | PageHero ← شبكة لوغوهات أكبر مع الاسم ← دعوة لاستعراض المشاريع. |
| **الشهادات** | PageHero ← بطاقات بأيقونة وثيقة ← لوحة السجل التجاري والرقم الضريبي + طلب النسخ. |
| **تواصل معنا** | PageHero ← نموذج ببطاقة بيضاء + بطاقات تواصل بأيقونات (كل وحدة رابط قابل للضغط) ← **خريطة Google** للمكتب الرئيسي. |

## 7. الجودة

- **إمكانية الوصول:** أهداف ضغط ≥ 44px، تباين ألوان AA، تركيز مرئي، `aria` للقوائم والفلاتر، `prefers-reduced-motion`.
- **الأداء:** الصور الكبيرة بتتحمّل عند الحاجة (lazy)، وأول صورة بالأولوية، والخريطة كمان lazy.
- **التحقق الآلي:**
  - `npm run check`: الروابط، والصور، والعناوين، وأوصاف السيو.
  - فحص على 7 مقاسات: تمرير أفقي، أهداف ضغط صغيرة، أخطاء الكونسول.
  - صور مقارنة قبل وبعد.

**نتيجة الفحص النهائي:** 14 صفحة × 7 مقاسات = 98 فحص.
- ولا حالة تمرير أفقي.
- ولا التفاف بالقائمة.
- كل العناصر القابلة للضغط ≥ 44px (إلا رابط "تخطَّ إلى المحتوى" المخفي اللي بيظهر بس مع لوحة المفاتيح).
- 8/8 اختبارات تفاعلية ناجحة: الفلاتر، النموذج وواتساب، معرض الصور، تبديل اللغة، قائمة الموبايل.

**مشكلة انكشفت وانحلّت أثناء الفحص:** لوحة قائمة الموبايل كانت بتنفتح بس ما بتبيّن، لأن تأثير الـ blur بالهيدر بيحبس العناصر الثابتة (fixed) جوّاه. انحلّت بنقل اللوحة لبرّا الهيدر، وصار في اختبار بيتأكد إنها بكامل ارتفاع الشاشة.
