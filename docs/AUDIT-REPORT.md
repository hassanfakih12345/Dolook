# تقرير الفحص والإصلاحات

## الأخطاء اللي انصلحت

### برمجية
| المشكلة | الإصلاح |
|---|---|
| كل الصفحات الإنكليزية كانت معرّفة `lang="ar"` على مستوى `<html>` | `<html lang dir>` صار حسب اللغة (ar/rtl، en/ltr) |
| أرقام الهاتف بالعربي كانت تنعرض مقلوبة (`4006 805 13 966+`) | الأرقام صارت دايماً من اليسار لليمين |
| الأسهم بالعربي كانت بعكس اتجاه القراءة (→ / ←) | الأسهم صارت تنقلب تلقائياً مع اتجاه الصفحة |
| زر "اطلب عرض سعر لهذا القسم" ما كان يختار القسم بالنموذج | صار يفتح صفحة التواصل والقسم مختار (`?division=`) |
| نموذج التواصل كان يتجاهل حقلي "الشركة" و"المساحة"، والرسالة بالإنكليزي حتى بالصفحة العربية | كل الحقول بتنبعت، والرسالة بلغة الصفحة |
| رسالة النجاح كانت تقول "تم استلام طلبك" مع إنو الطلب بس انفتح بواتساب | الرسالة صارت واضحة: "اضغطوا إرسال بواتساب"، مع زر لطلب جديد |
| كل الصفحات إلها نفس العنوان والوصف | كل صفحة إلها عنوان ووصف وcanonical وhreflang وصورة مشاركة |
| ما في `sitemap.xml` ولا `robots.txt` | انضافوا (50 صفحة مع روابط اللغتين) |
| صفحة 404 كانت صفحة Next.js الإنكليزية الافتراضية بلا تصميم | صفحة 404 بتصميم الموقع وبلغتين + `ErrorDocument` بـ `.htaccess` |
| "— CEO" كانت بالإنكليزي بالصفحة العربية | "الرئيس التنفيذي" |
| القائمة بالموبايل: زر بلا وصف بالعربي، ما بتسكّر بـ Esc أو عند تغيير الصفحة | انصلحت + أيقونة × عند الفتح |
| ما في إشارة للصفحة الحالية بالقائمة | الصفحة الحالية مميّزة (`aria-current`) |
| رابط "تخطَّ إلى المحتوى" مفقود (إمكانية الوصول) | انضاف |
| صور البطاقات كانت مقصوصة 4:3 والصور الأصلية 16:9 | البطاقات صارت 16:9 وما في شي مقصوص |
| ملفات Next.js الافتراضية (`next.svg`, `vercel.svg`...) بمجلد public | انحذفت |

### الترابط بين الصفحات
- **الرئيسية** كانت فيها بس الواجهة. انضاف: الأرقام، الأقسام، المشاريع المميزة، القطاعات، العملاء، كلمة الرئيس التنفيذي، ودعوة للتواصل (كل نصوصها كانت موجودة بالترجمات بس مش مستعملة).
- **صفحة المشروع** كانت نهاية مسدودة: انضاف رابط للقسم، "مشاريع أخرى"، وطلب عرض سعر مع القسم.
- **صفحة القسم**: انضاف "أقسام أخرى"، رابط لكل مشاريع القسم، ورسالة لما القسم ما إله مشاريع منشورة (الصيانة والتشغيل).
- **المشاريع**: الفلتر صار يبيّن عدد المشاريع، وبينحفظ بالرابط فيك تشاركه.
- **الفوتر**: صار فيه كل الصفحات + واتساب.
- **Breadcrumbs** بكل الصفحات الداخلية.
- النتيجة: ولا صفحة يتيمة، كل الروابط شغالة (مفحوصة بـ `npm run check`).

## شغلات بتحتاج منك (ما بقدر أعملها أنا)

1. **صور المشاريع**: الصور الحالية لقطات صغيرة (341×192) من بروشور الشركة وعليها كتابة. لما تبعتلي صور حقيقية بدقة عالية لكل مشروع بحطها.
2. **صورة الرئيس التنفيذي**: `public/brand/ceo.png` كمان لقطة من البروشور. إذا عندك صورة شخصية واضحة بضيفها لصفحة "عن الشركة".
3. **الدومين**: الروابط بالـ sitemap مبنية على `https://dolook.sa`. إذا الدومين غير هيك قلّي.
4. **HTTPS**: بعد ما تفعّل SSL بـ cPanel، شيل علامة `#` من سطرين "Force HTTPS" بـ `.htaccess`.
5. **قسم الصيانة والتشغيل** ما إله ولا مشروع منشور. إذا عندك مشاريع صيانة ابعتلي تفاصيلها.
6. **الشهادات**: الصفحة فيها أسماء الوثائق بس. إذا بدك تنعرض نسخ PDF منها ابعتلي ياها.
7. **الأرقام**: "63 متخصص" و"+25 سنة خبرة" (بتنحسب تلقائياً من 2001) — تأكد إنها صحيحة.
